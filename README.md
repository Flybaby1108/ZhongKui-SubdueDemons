# Vacuum Cleaner Master

> 一款致敬经典街机《Tumble Pop》的 2D 像素平台游戏。
> 主角拿着吸尘器横扫怪物世界 —— 吸进去，吐出来，撞翻一片！

---

## 项目角色分工

| 角色 | 谁负责 | 工作内容 |
|------|--------|---------|
| **美术** | 你 | 角色/敌人/道具/地形/UI 像素图，动画帧 |
| **策划** | 你 | 关卡设计、敌人行为、数值、玩法机制 |
| **程序** | Sisyphus | Godot 项目搭建、所有代码、导出发布 |

---

## 技术方案

- **引擎**：Godot 4.x（免费开源）
- **语言**：GDScript（Godot 内置脚本，类似 Python）
- **目标平台**：PC（Mac / Windows）+ 网页版（HTML5）
- **像素分辨率**：320×240 逻辑分辨率

## 协作流程

### 你的工作流

1. **看 [ART_GUIDE.md](./ART_GUIDE.md)** 了解美术规格
2. **看 [DESIGN.md](./DESIGN.md)** 了解游戏设计（你也可以改）
3. **画素材** → 放进 `assets/` 对应目录
4. **告诉我"X 资产已交付"**，我会替换游戏中的占位图
5. **试玩 → 反馈** → 我调整

### 我的工作流

1. 用占位图（彩色方块）先把游戏跑起来
2. 你交付素材，我替换 → 你试玩 → 调整
3. 你发现 bug 或想法 → 告诉我 → 我改

### 沟通规则

- 你**不需要懂代码**，用自然语言告诉我想要什么效果
- 比如：「主角跳得太高了，应该更短促」「这个敌人移动太慢」
- 我把你的需求翻译成代码
